# DavinTelop

**DaVinci Resolve / Premiere Pro 向け テロップ作成ツール**

CSV読み込みまたは直接入力でテロップデータを管理し、透過PNG・SRT・FCPxml の書き出し、DaVinci Resolve への直接配置まで対応した Windows 用デスクトップアプリです。

---

## 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11 (64bit) |
| .NET / ランタイム | 不要（スタンドアロン EXE） |
| DaVinci Resolve | 18 以降（API連携使用時） |
| Premiere Pro | CC 2020 以降（合成プレビュー使用時） |

---

## インストール

1. `DavinTelop_vX.X.X.zip` を任意のフォルダに解凍
2. `DavinTelop.exe` をダブルクリックして起動

インストール作業は不要です。レジストリへの書き込みも行いません。

## 主な機能

| 機能 | 概要 |
|---|---|
| CSVインポート | start / end / text 列を持つ CSV を読み込み |
| 直接入力 | タイムコード + テキストをその場で入力して追加 |
| デザイン設定 | フォント・縁取り・シャドウ・背景・位置を GUI で調整 |
| リアルタイムプレビュー | 設定変更が即座にプレビューに反映 |
| PNG 書き出し | テロップ1枚ずつ透過 PNG として書き出し |
| SRT 書き出し | 字幕ファイル（SRT形式）として書き出し |
| FCPxml 書き出し | Final Cut Pro XML でタイムライン情報を書き出し |
| Resolve スクリプト生成 | DaVinci Resolve コンソール用 Python スクリプトを生成 |
| Resolve API 送信 | DaVinci Resolve が起動中であれば直接タイムラインに配置 |
| 合成プレビュー | Premiere Pro / Resolve の映像に Photoshop PNG を重ねて確認 |
| プリセット管理 | デザイン設定をプリセットとして保存・呼び出し |

### テロップ作成・編集

| 機能 | 概要 |
|---|---|
| TC 自動反映 | 新規作成ダイアログの開始/終了TCを自動入力（選択の直後・最後の直後・Resolve再生ヘッド・直接入力欄から選択可） |
| Enter で作成 | テキスト入力後 Enter で作成、Shift+Enter で改行（キーは「キーボードショートカット設定」で変更可） |
| 連続入力 | 作成後もダイアログを閉じず、次のテロップの TC を自動で進めて続けて入力 |
| ◉ 再生ヘッド | ダイアログから Resolve の再生ヘッド位置を開始TCに取り込み |
| 文字数で尺 | 文字数 ÷ 速度（文字/秒）で尺を自動計算。一括再計算も可 |
| TC 入力補助 | ↑↓ で ±1フレーム、Shift+↑↓ で ±1秒、`1234` → `00:00:12:34` の自動整形 |
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Y（テロップリストの全操作が対象） |
| 絞り込み・検索と置換 | リスト上部の 🔎 欄で絞り込み、Ctrl+Shift+F で一括置換（正規表現対応） |
| 一括編集 | TC順ソート / TC一括シフト / 結合 / 改行で分割 / 隙間を埋める / 無効テロップ削除 |
| コピー＆貼り付け | Ctrl+C で TSV コピー、Ctrl+V で TSV または台本テキスト（1行=1テロップ・TC自動割当）を貼り付け |
| TC チェック | 不正TC・終了≦開始を赤、時間の重なりを橙で表示し、一覧で報告 |
| SRT 読み込み / CSV 書き出し | SRT からテロップを取り込み、CSV（Excel 互換）で書き出し |
| Resolve へジャンプ | 選択テロップの開始TCへ Resolve の再生ヘッドを移動（Ctrl+J） |
| リスト操作キー | F2 詳細編集 / Enter ダイアログ編集、Insert 直後に挿入、Space 有効切替、Ctrl+D 複製、Alt+↑↓ 並べ替え、ドラッグで並べ替え |

### 画面構成と加工機能

| 機能 | 概要 |
|---|---|
| ツールバー | 上部に保存・元に戻す・新規テロップ・加工・読込/書出・Resolve 操作を集約（各ボタンにツールチップ） |
| 詳細編集パネル | リスト下でテキスト・TC・尺・話者・メモを直接編集。複数選択時は話者・尺・有効・スタイルを一括変更 |
| 個別スタイル | テロップごとに文字色・縁色・サイズ・位置を上書き（コピー／貼り付け／解除）。PNG 書き出し・Resolve 配置に反映 |
| タイムライン | 画面下部でテロップをブロック表示。ドラッグで移動、端ドラッグで尺調整、隣接スナップ、Ctrl+ホイールでズーム、空き部分ダブルクリックで新規 |
| 加工 ▸ テキスト | 2行/3行に均等改行、N文字で改行、1行に、空白整理、句読点削除、文末「。」削除、三点リーダー統一、フィラー除去、半角/全角変換、括弧で囲む/外す、先頭・末尾に追加、話者名の分離 |
| 加工 ▸ タイミング | 尺の一括設定、最小尺の確保、文字数から再計算、隙間なく連続配置、隙間を埋める、TCシフト、I/O キーで再生ヘッドに合わせる、[ ] で 1フレーム・Shift で 1秒移動 |
| CSV 文字コード自動判別 | UTF-8 / Shift_JIS / EUC-JP / UTF-16 を自動で判別（読込メニューで固定も可） |

## クイックスタート

### テロップを作って Resolve に配置する（基本フロー）

1. DaVinci Resolve を起動し、プロジェクト・タイムラインを開いておく
2. DavinTelop を起動
3. 「直接入力」エリアで開始TC・テキストを入力 → **追加** ボタン
4. デザインパネルでフォント・スタイルを調整
5. 下部バーの「出力先」フォルダを指定
6. **⚡ Resolve API送信** ボタンをクリック

### Resolve API が使えない場合

1. 上記手順 1〜5 を実施
2. **🐍 Resolveスクリプト生成** ボタンをクリック
3. Resolve で `Workspace > Console` を開く
4. 生成された `davintelop_resolve.py` をコンソールにドラッグ＆ドロップ
5. Enter キーで実行

---

## DaVinci Resolve API の有効化

Resolve 側で外部スクリプトを許可する設定が必要です。

`DaVinci Resolve > Preferences > General`
→ **External scripting using: Local** に設定
→ Resolve を再起動

## アンインストール

解凍したフォルダを削除するだけです。
設定ファイルが `C:\Users\ユーザー名\.davintelop\` に保存されますので、
完全に削除する場合はこのフォルダも削除してください。
