# TeloCut（テロカット）

テロップ制作、音声合成、素材管理まで行える Windows 向け動画編集ソフトです。テロップ編集ソフト **DavinTelop**、素材サーバー用アプリ **TeloCutAssets** も同梱しています。

## ダウンロード

現在公開している最新版は **v0.32.1** です。無料版と有料版の配布ファイルは、GitHub のファイルサイズ制限に合わせて 3 分割されています。

- [無料版 v0.32.1 のダウンロードと結合方法](downloads/free/README.md)
- [有料版 v0.32.1 のダウンロードと結合方法](downloads/paid/README.md)

各案内ページから `.001`、`.002`、`.003` をすべてダウンロードし、記載の手順で zip に結合してください。無料版は書き出しに透かしが入ります。有料版はライセンスキーで Pro / Studio を有効にできます。キーがない場合も無料版の機能と Pro の 14 日間試用を利用できます。

## 動作環境

- Windows 10 / 11（64 ビット）
- メモリ 8 GB 以上。4K 編集では 16 GB 以上を推奨します。
- NVIDIA GPU と NVENC 対応 FFmpeg があれば、再生、プロキシ作成、書き出し、文字起こしに GPU を利用できます。GPU がなくても動作します。

## インストールと起動

1. ダウンロードした zip を任意のフォルダーに展開します。
2. `TeloCut.exe` を起動します。インストール作業は不要です。
3. 基本操作はアプリ内の **ヘルプ → ガイドブック** をご覧ください。

| アプリ | 用途 |
|---|---|
| `TeloCut.exe` | 動画編集 |
| `DavinTelop.exe` | テロップ編集。TeloCut と併用すると再生位置などが連動します |
| `TeloCutAssets.exe` | 素材サーバーの素材検索・取り込み |
| `TeloCutCLI.exe` | レンダーノード、サーバー、Claude Code 連携用のコマンドライン |

## 主な機能

- **動画編集**: マルチトラックのタイムライン、プロキシ、トランジション、エフェクト、Undo / Redo、プロジェクト健全性チェック、マルチディスプレイ、ペンタブレット対応。
- **音声**: オーディオミキサー、音声波形、音量・パン調整、VOICEVOX などの音声合成、無音カット。
- **テロップ・字幕**: DavinTelop 連携、テンプレート、縦書き、縁取り・光彩、文字起こし、SRT などの字幕ファイル。
- **キャラクター**: 立ち絵の目パチ・口パク・呼吸、MMD モデルからの立ち絵生成、セリフに合わせた MMD モーション。
- **取り込み・収録**: OBS 録画の自動取り込み、Blackmagic Desktop Video 機器からの収録。
- **合成・連携**: Blender 合成、DaVinci Resolve、Photoshop、After Effects、Claude Code（MCP）、ComfyUI、素材サーバー。
- **書き出し・公開**: H.264 / H.265、ProRes、DNxHR、透過動画、プロキシ、YouTube 公開ワークフロー。
