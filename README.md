# TeloCut（テロカット）

テロップに強い Windows 用の動画編集ソフトです。テロップ編集ソフト **DavinTelop** と、素材サーバー用アプリ **TeloCutAssets** も同じ zip に入っています。

## ダウンロード

右の **Releases** から、最新版の zip をダウンロードしてください。

| ファイル | 内容 |
|---|---|
| `TeloCut_v0.25.0_free.zip` | **無料版**。だれでも使えます |
| `TeloCut_v0.25.0_paid.zip` | **有料版**。ライセンスキーで Pro / Studio になります。キーが無くても無料版の機能と、Pro の 14 日間お試しが使えます |

## 動作環境

- Windows 10 / 11（64 ビット）
- メモリ 8GB 以上（4K の編集は 16GB 以上をおすすめ）
- NVIDIA の GPU があれば、再生・プロキシ作成・書き出し・文字起こしに自動で使います（無くても動きます）
  - GPU を使うには、NVENC 入りの ffmpeg（例: `winget install Gyan.FFmpeg`）が必要です

## 使い始める

1. zip を好きな場所に展開します（例: `C:\TeloCut`）。インストールは不要です
2. `TeloCut.exe` を起動します
3. 使い方はメニューの **ヘルプ → ガイドブック** を見てください

| ファイル | 役割 |
|---|---|
| `TeloCut.exe` | 動画編集 |
| `DavinTelop.exe` | テロップ編集（TeloCut と同時に使うと、テロップと再生位置が連動します） |
| `TeloCutAssets.exe` | アセットサーバーの素材を探す・取り込む |
| `TeloCutCLI.exe` | コマンド版（レンダーノード・サーバー・Claude Code 連携） |

## おもな機能

- **編集**: Avid Media Composer 風の画面とキー操作（Premiere Pro 風にも切り替え可）、マルチディスプレイ、ペン（板タブ・液タブ）対応
- **テロップ**: DavinTelop と連携、テンプレート、グラデーション・二重縁・光彩・縦書き、文字起こしで字幕
- **キャラクター・声**: VOICEVOX などの音声合成、立ち絵の目パチ・口パク・呼吸、MMD のモデルから立ち絵、MMD をセリフに合わせて動かす、英語の声を日本語に吹き替え
- **取り込み・収録**: OBS の録画を自動で取り込み・無音カット、Blackmagic（Desktop Video）の機器から収録
- **書き出し・公開**: YouTube 公開まで自動（書き出し・サムネイル・概要欄・アップロード）、ショート動画、各種の字幕ファイル
- **連携**: DaVinci Resolve、Photoshop、After Effects、Blender、Claude Code（MCP）、アセットサーバー
