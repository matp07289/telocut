# TeloCut を公開・販売するための計画

## 1. エディション（アプリに実装済み）

| | 無料版 | Pro | Studio |
|---|---|---|---|
| 対象 | 個人・お試し・ゆっくり実況 | 個人のクリエイター・副業 | 小さな制作会社・チーム |
| 編集・テロップ・テンプレートを使う・ゆっくり・biim 式の配置 | ✓ | ✓ | ✓ |
| 書き出し | H.264 / H.265・1080p まで | 4K 以上・DNx / ProRes / QuickTime・透明 | 同左 |
| 自動切り抜き | 透かし「Made with TeloCut Free」付き | 透かしなし | 透かしなし |
| トランスコード・モーション（トラッキング / 手ぶれ補正）・Blender / MMD・Dynamic Link・AI | — | ✓ | ✓ |
| テンプレートの作成・保存 | — | ✓ | ✓ |
| ファーム（複数 PC で書き出し / 変換）・制作管理 | — | — | ✓ |
| お試し | Pro を 14 日間（1 回） | | |

- 無料版でも「作れる」ようにして使い始めてもらい、仕上げ（高画質・プロ用の形式・透かしを消す・作業の自動化）で払ってもらう形です。
- 境目は `editor/license.py` の `FEATURES`（機能と、必要なエディション）にまとまっています。ここを書き換えれば調整できます。

## 2. 値段の案

| | 買い切り | サブスクリプション |
|---|---|---|
| Pro | 9,800 円（1 年分のアップデート込み・2 年目からは更新 4,800 円） | 月 980 円 / 年 9,800 円 |
| Studio | 1 席 29,800 円（同上） | 1 席 月 2,980 円 |

- レンダーノード（TeloCutCLI を動かすだけの PC）は席に数えません。チームが台数を増やすほど得になり、Studio を選ぶ理由になります。
- 学生・個人 VTuber 向けの割引（例: 30% 引きのクーポン）を、発売直後に期間限定で配ると広まりやすくなります。

## 3. ライセンスキーの発行（仕組みは実装済み）

1. 秘密鍵: `C:\Users\<あなた>\.telocut_dev\license_signing_key.txt`（リポジトリの外。**必ずバックアップ**し、人に渡さない・Git に入れない）
2. 購入があったら、キーを作ってメールで送る:
   ```
   python tools/make_license.py --name "購入者名" --email buyer@example.com --edition pro
   python tools/make_license.py --name "制作会社A" --email a@example.com --edition studio --seats 5
   python tools/make_license.py --name "月額の人" --email b@example.com --edition pro --days 31
   ```
3. 購入者は TeloCut の「設定 → ライセンス」にキーを貼るだけ（ネット接続は不要）。
4. 販売ページの URL は、環境変数 `TELOCUT_PURCHASE_URL` か `editor/license.py` の `PURCHASE_URL` に入れておく（ライセンス画面の「購入ページを開く」で開く）。

キーは Ed25519 で署名しているので、アプリの中身を見られてもキーは作れません（アプリには公開鍵しか入っていない）。ただし、アプリそのものを書き換えれば制限は外せます。これはどの買い切りソフトでも同じで、「正しく払う方が楽」な状態（アップデート・サポート・テンプレート配布）を作るのが現実的な対策です。

### 販売の窓口（候補）
- **BOOTH（pixiv）**: ゆっくり実況・VTuber 層に強い。ダウンロード販売＋キーを手で送る。手数料が安い
- **Gumroad / Lemon Squeezy**: 海外向け・ライセンスキーの自動発行や、サブスクリプションに対応。Webhook でキー発行を自動化できる
- **Stripe ＋ 自前のページ**: 手数料が最も安い。キー発行を自動化するには、Webhook で `make_license.py` を呼ぶ小さなサーバーが要る

## 4. 【重要】公開・販売の前に必ず確認すること（使っている部品のライセンス）

| 部品 | ライセンス | 有料で、ソースを公開せずに配る場合 |
|---|---|---|
| **PyQt6**（画面） | **GPL v3 か、Riverbank の商用ライセンス** | GPL のままでは、ソースコードを GPL で公開する義務がある。避けるには、**PyQt の商用ライセンスを買う**か、**PySide6（LGPL）に移す**（API はほぼ同じで、移す作業は数日程度） |
| **PyAV が同梱する FFmpeg**（x264 / x265 入り） | **GPL** | 同上。**x264 / x265 を含まない LGPL ビルドの FFmpeg に差し替え**（H.264 は Windows の Media Foundation `h264_mf` や NVENC で書き出す）か、x264 の商用ライセンスを取る |
| faster-whisper / CTranslate2 | MIT | そのまま使える（著作権表示を同梱） |
| Pillow・NumPy・psd-tools・OpenCV | MIT / BSD / Apache 系 | そのまま使える（著作権表示を同梱） |
| Whisper のモデル | MIT | 同上 |

**選び方**

| | 選択肢 A | 選択肢 B |
|---|---|---|
| 公開の仕方 | ソースを GPL で公開したまま、有料版を売る | ソースを公開しない |
| 必要なこと | 特になし（ビルド済みの EXE・サポート・アップデート・テンプレート集を売る） | PySide6 への移行と、LGPL の FFmpeg への差し替え（または商用ライセンスの購入） |
| 向いている場合 | 早く出す | 長く売る |

GPL で公開しても有料販売はできます。ただし、買った人がソースから自分でビルドして配ることは止められません。

## 5. 発売までの手順（おすすめ）

1. 上の 4 を決める。
2. 利用規約・プライバシーポリシー・特定商取引法に基づく表記のページを作る（ブラウザ版アセットサーバーは LAN の中だけで、アプリは外部に何も送らないことを明記）。
3. 公開用の Gitea / GitHub のリリースページ、またはダウンロードページを用意し、EXE（zip）にコード署名をする（Windows の SmartScreen の警告を減らす）。
4. 無料版で、ゆっくり実況・切り抜きの人たちに使ってもらう（テンプレート集・biim 式の作例動画を一緒に配る）。
5. 反応を見て、Pro の境目と値段を調整する（`FEATURES` を変えるだけ）。
