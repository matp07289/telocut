TeloCut ガイドブック

はじめての人が、1 本の動画を作って書き出すまでを順番に案内します。後半は、ゆっくり実況・biim 式・配信の切り抜きなど、目的別の作り方です。

0はじめに

TeloCut（テロカット）は、テロップづくりに強い動画編集ソフトです。画面とキー操作はプロ用の編集ソフト Avid Media Composer と同じ並びで、Premiere Pro 風の並びにも切り替えられます。

テロップが速い

テンプレートから選んで置くだけ。字幕は文字起こしで自動作成

ゆっくり・biim 式

台本から音声・字幕・立ち絵を一括配置。RTA タイマーも自動

切り抜きを自動で

配信アーカイブから見どころを探し、無音を詰めて字幕まで

この PC の中で完結

音声認識も書き出しもローカル。素材が外に送られることはありません

エディション（無料版・Pro・Studio）

このガイドで Pro や Studio の印が付いた機能は、そのエディションで使えます。今のエディションはウィンドウのタイトルと 設定 → ライセンス で確認できます。

1インストールと起動

  1. ダウンロードした zip を右クリック → すべて展開。できたフォルダ TeloCut を好きな場所（例: C:\TeloCut）に置きます。インストーラーはありません。
  2. フォルダの中の TeloCut.exe をダブルクリックします。「Windows によって PC が保護されました」と出たら 詳細情報 → 実行。
  3. 「プロジェクトの選択」が開きます。新規作成 を押し、名前・テンプレート・解像度（例: 1920×1080）・フレームレート（例: 30）を選んで OK。
ヒントテンプレートで「ゆっくり実況」「biim 式」「ショート」「インタビュー」を選ぶと、必要なトラック・ビン・形式が最初からそろいます。迷ったら「空」で大丈夫です。

フォルダには ほかに DavinTelop.exe（テロップ専用の編集ソフト。TeloCut と連動します）と TeloCutCLI.exe（サーバーやレンダー用 PC で使うもの）が入っています。普段は TeloCut.exe だけ使えば十分です。

機能を探す

ツールバー右の検索欄（Ctrl+Alt+F）に「ピー」「書き出し」のように入れて Enter。メニューから使うと、キーがある機能はステータスバーでキーを教えてくれます。

ヒントメニューが多すぎると感じたら ウィンドウ → メニュー: かんたん / すべて を切り替え。よく使うメニューだけになります。モニターとタイムラインだけにしたいときはフォーカスモード（F11。Avid の並びでは Shift+F11）。

3最初の 1 本を作る

撮った動画を並べて、テロップを入れて、MP4 で書き出すまでの流れです（キーは Avid 標準の並び。Premiere 風の並びは付録を見てください）。

  1. 素材を読み込む — Ctrl+I で動画・画像・音声を選ぶか、エクスプローラーからビンへドラッグ＆ドロップ。
  2. 素材を見る — ビンの素材をダブルクリックすると、左のソースモニターに表示されます。Space で再生 / 停止、J K L で巻き戻し・停止・早送り（押すたびに速くなる）。
  3. 使う範囲を決める — 始まりで I、終わりで O。
  4. タイムラインに置く — V（スプライスイン = 後ろを押し出して挿入）か B（上書き）。再生ヘッドの位置に入ります。2〜4 をくり返して並べます。
  5. いらない部分を消す — タイムラインで範囲に IN / OUT を付けて X（抽出 = 詰める）か Z（リフト = すき間を残す）。間違えたら Ctrl+Z。
  6. テロップを入れる — テロップを出したい位置に再生ヘッドを置いて Ctrl+Shift+L（テロップのテンプレート）。種類を選び、文字を入れて 配置。すぐ入れるだけなら Shift+T。
  7. テロップを直す — タイムラインでテロップを選ぶと、右のエフェクトエディターで文字・フォント・色・縁取り・位置を変えられます。 位置と大きさはモニターで直接: レコードモニターをダブルクリックすると枠が出るので、中をドラッグで移動・角で大きさ・角の外で回転（中心や端にぴったり付きます。矢印キーで 1px）。
  8. 保存 — Ctrl+S。自動保存（5 分ごと）とバックアップ（Attic）もあります。
  9. 書き出し — Ctrl+E。形式は「H.264（MP4）」のままで OK。保存先を選んで書き出します。
ヒントタイムラインの上に赤い線が出ている所は、重くてそのままでは滑らかに再生できない区間です。再生 → レンダリング・プロキシ → 要レンダリング部分をすべてレンダリング で滑らかになります。

4テロップを作り込む

テンプレートで置く

Ctrl+Shift+L で、14 種類のテンプレート（字幕・ロワーサード・見出し・テロップ帯・ツッコミ・強調・吹き出し・速報・場所 / 日時・ゆっくり霊夢 / 魔理沙・引用・エンドクレジット・カウントダウン）から選べます。 {名前} のような差し込み欄を埋めると、プレビューで仕上がりを確認してから置けます。

自分で作ったテロップは、タイムラインで選んで テロップ → 選んだテロップをテンプレートとして保存 すれば次から同じ見た目で使えます Pro。

字幕を自動で作る

  1. テロップ → 文字起こしで字幕を作成。音声を聞き取って、読みやすい長さ（10〜20 文字ほど）で区切った字幕を並べます。
  2. ウィンドウ → テロップ一覧 で、表のまま誤字を直せます。
  3. テロップ → 整える・直す → テロップの読みやすさチェック で、読む速さが速すぎる字幕にマーカーが付きます。

見た目を一気にそろえる

  • テロップスタイル: YouTube 黄色・極太縁・強調・ニュース帯などをワンクリック
  • テロップ → テロップのフォントを一括変更 / テロップ → 整える・直す → はみ出すテロップを画面に収める
  • 文字アニメ（ポップ・スライドアップ・タイプライター）とカラオケ表示
  • 細かい編集は Ctrl+Shift+T のテロップエディター（DavinTelop と同じ画面）
ヒントプロジェクトでいつも同じテロップを使うなら、設定 → プロジェクト設定 の「新しいテロップの既定テンプレート」に入れておくと、Shift+T でそのテンプレートが入ります。

5ゆっくり実況・解説動画

  1. キャラクターを登録 — キャラクター・声 → キャラクター（立ち絵）を登録。口閉じ・口開き・目閉じの PNG を選ぶか、PSD から自動で作ります。
  2. 台本を書く — 「霊夢：こんにちは」「魔理沙：今日は〜」のように、1 行に 1 セリフ。
  3. 一括生成 — Ctrl+Alt+Y（台本から一括生成）に台本を貼ると、音声（VOICEVOX か Windows の音声）・字幕・立ち絵がまとめて並びます。口パクとまばたきも自動です。
  4. セリフを直す — Ctrl+Shift+Y のセリフパネルで文を直すと、その音声だけ作り直し、長さが変わった分は後ろを自動で詰めます。
  5. BGM と効果音 — オーディオ → BGM を最後までループ。オーディオ → 選択トラックのダッキング で、声の所だけ BGM が自動で下がります。効果音は SE パッドからクリックで置けます。

メニューの並び（v0.25 から）

上のメニューは仕事の流れの順です: ファイル / 編集 / クリップ / シーケンス / テロップ / オーディオ / 再生 / キャラクター・声 / 演出 / 取り込み・収録 / 書き出し・公開 / チェック・管理 / 連携 / 設定。 場所がわからないときは、ツールバーの「🔍 やりたいこと」に言葉を入れると探せます。

MMD のキャラクターをセリフに合わせて動かす

  1. キャラクター・声 → MMD をセリフに合わせて動かす を開き、モデル（PMX）と声の音声トラックを選びます。
  2. 使う身振り（説明する手・両手を広げる・胸に手・指さし など）と大きさ、うなずき・体の揺れ・まばたきを選んで「作る」。
  3. Blender が背景透明の動画を作り、声の位置に置きます。「MME 風エフェクト」でアニメ調にもできます（そのクリップだけに掛かります）。

ずんだもん などの立ち絵を目パチ・口パクに（立ち絵メーカー）

  1. キャラクター・声 → 立ち絵メーカー を開き、「フォルダ…」で立ち絵の素材のフォルダ（または PSD・PsdSplitter の JSON）を選びます。
  2. 左のリストで衣装・表情を選びます（◉ は 1 つだけ）。右の「目パチ」「口パク」は名前から自動で入っています。プレビューの「▶ 動かして見る」で確認。
  3. まばたきの間隔・ばらつき、口が開く音の大きさを好みに。「テンプレートとして保存」で「ずんだもん 通常」のように名前を付けて残せます。
  4. 「作ってタイムラインに置く」で、選んでいる音声トラックの声に合わせて口パクします。次からは キャラクター・声 → 立ち絵テンプレートから置く で選ぶだけ。
注意VOICEVOX を使うときは、VOICEVOX を先に起動しておいてください。動画の概要欄には「VOICEVOX:キャラ名」のクレジットが必要です（書き出し・公開 → 概要欄テキスト で自動で入ります）。

6biim 式の RTA 動画

  1. 新規プロジェクトのテンプレートで biim 式 を選びます（あとからでも OK）。
  2. ゲーム画面の動画をタイムラインに置き、そのクリップを選びます。
  3. 演出 → 素材の配置テンプレート で配置を選びます: biim 全画面 / サイド / 4:3＋余白 / ワイプ / 比較。
  4. ゲーム画面・RTA タイマー・区間名・倍速の表示（×N）・立ち絵・話者ごとの色の字幕がまとめて置かれます。
  5. 区間の切れ目（ボス撃破など）で Ctrl+Alt+W（区間を追加）。タイマーに区間名と区間タイムが出ます。
ヒントタイマーはゲーム映像の再生位置から計算するので、倍速やカットをしても実際のゲーム内の時間を表示し続けます。

7配信の切り抜き（自動切り抜き）

Ctrl+Alt+Q。長い配信アーカイブから、自動で 9 割まで作ってくれます。残りは手で直すだけです。

  1. 配信の動画をドラッグ＆ドロップ。あればチャットのログや配信マーカーも入れると、見どころ探しが正確になります。
  2. 作るものを選ぶ: 見どころを切り抜く / 全体を 1 本に / 縦動画に。
  3. 実行 → 音の大きさのグラフと、見どころの候補（点数の高い順）が出ます。候補をクリックするとその場面を確認できます。無音カットのしきい値もここで調整。
  4. OK → 選んだ区間ごとにシーケンスができ、無音を詰め、字幕を付けます。
  5. 字幕を確認（誤字を直す・いらない字幕を外す・話者を選ぶ）→ 字幕決定 → 書き出し（音量は −14 LUFS にそろえます）。
注意無料版は書き出しに小さな透かし「Made with TeloCut Free」が入ります。Pro 以上で消えます。

YouTube にアップロード

  1. はじめに 1 回だけ: Google Cloud で「YouTube Data API v3」を有効にして、OAuth クライアント ID（種類: デスクトップ アプリ）を作り、JSON をダウンロードします。
  2. 書き出し・公開 → YouTube にアップロード（仕上げのページの「▶ YouTube へ」）。「設定ファイルを選ぶ」でその JSON を読み込み、「Google にログイン」→ ブラウザで許可。
  3. 最後に書き出した動画・タイトル・概要欄（チャプター）が入っています。公開範囲・予約公開・サムネイル・再生リストを選んで「アップロード」。終わると URL がコピーされます。
注意Google の審査を通していないクライアントで上げた動画は「非公開」になります（YouTube の決まり）。途中で切れたら「アップロード履歴」の「続きから送る」。

9書き出しと変換

Ctrl+E で書き出し画面を開きます。よく使う設定は プリセットとして保存 しておけます。

形式使いどころ
H.264（MP4）YouTube・SNS への投稿。迷ったらこれ
H.265（MP4）同じ画質でファイルを小さくしたいとき
ProRes / DNxHR（MOV / MXF） Proほかの編集ソフトに渡す・高画質で保存する
透明付き（ProRes 4444 など） Proテロップだけを別のソフトで重ねる

トランスコード Pro: 書き出し・公開 から、素材をまとめて編集しやすい形式（DNxHR LB など）に変換できます。

ほかの編集ソフトとのやり取りは ファイル → 他ソフトから読み込み（Ctrl+Alt+I）と 書き出し・公開 → 他の形式で書き出し。AAF・Premiere Pro・Final Cut Pro XML・EDL に対応しています。

103D テロップ（Blender） Pro

  1. Blender をインストールしておきます（ふつうの場所に入れれば TeloCut が自動で見つけます。見つからないときは環境設定で blender.exe の場所を指定）。
  2. 演出 → モーション・3D → 3D テキスト（Blender） を開き、テンプレートを選んで文字などを決めて OK。Blender が裏で動いて、できた映像がタイムラインに入ります。
  3. 直したいときは、その 3D テロップを選んで 演出 → モーション・3D → 3D テロップを直す（Blender）。同じ場所で作り直されます。
  4. 気に入った設定は「テンプレートとして保存」で、次から選べるようになります。

11自分好みにする

配色

設定 → ユーザー設定 → 配色。Avid・Avid Blue・Graphite・Midnight・Forest・Warm・Light・High Contrast の 8 種類。明るさ・アクセント色・文字の大きさも変えられ、選ぶとすぐ反映されます（キャンセルで元に戻ります）。

3 つの設定の違い

設定中身どこに残る
ユーザー設定配色・ショートカット・編集と再生のくせ・書き出しプリセット人ごと（ユーザーを切り替えられる・ほかの PC に持っていける）
プロジェクト設定解像度・fps・既定のテロップ・書き出し先・メモ・作業時間そのプロジェクトの中
環境設定ドライブ・キャッシュの場所・サーバーなどこの PC

保存と書き出しの名前

チェック・管理 → 保存のたびにバックアップするフォルダ を決めると、保存するたびに日時付きのコピーが残ります（新しい 20 個）。 書き出し・公開 → 書き出しファイル名のルール で「{project}_{seq}_v{v}」のようにすると、書き出しの名前が自動で付き、版の番号も増えます。

画面と操作

設定 → ユーザー設定 → 画面と操作 で、メニュー（かんたん / すべて）・ツールバーの大きさ・パネルの配置のロック・スタート画面・書き出しが終わったときの知らせ方を選べます。

ショートカット

設定 → キーボード設定。画面のキーボードに、コマンドをドラッグして割り当てます。「Avid 標準」と「Premiere 風」のプリセットがあります。

12チームで使う

  • 共有プロジェクト: プロジェクトを NAS に置けます。だれかが開いていると「だれがどの PC で」と表示され、ほかの人は読み取り専用で開けます。
  • アセットサーバー: 素材を検索・★・タグ付けして共有。ブラウザからも使えます（http://サーバー:8770/）。
  • ファーム Studio: 書き出しや変換を、複数の PC に分けて速く終わらせます。手伝う PC では TeloCutCLI.exe --render-node --server http://サーバー:8770 を動かします。
  • 制作管理 Studio: ショット・担当・期限をブラウザと TeloCut の両方で管理します。

13困ったとき

こまりごとやること
赤い「メディアオフライン」の画面が出る素材ファイルが移動・削除されています。ビンで右クリック → オフライン素材を再リンク で、新しい場所を選びます
再生がカクカクするレンダリング（赤い線の区間）か、重い素材のプロキシ作成。4K 素材はプロキシがおすすめ
間違えて保存してしまったファイル → Attic（バックアップ）から復元 で、前の版に戻せます（30 世代まで）
キーが効かない・どれか忘れたF1 で一覧。Ctrl+Shift+P で名前から実行
「Pro の機能です」と出る設定 → ライセンス でキーを登録（有料版）。有料版なら 14 日間のお試しもできます
落ちてしまった自動保存（5 分ごと）と ファイル → Attic（バックアップ）から復元 で、直前の状態に戻せます。原因は %USERPROFILE%\.davintelop\telocut_crash.log に残ります（問い合わせのときに添えてください）
