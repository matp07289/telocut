# TeloCut（テロカット）— テロップに強い動画編集ソフト

Avid Media Composer の画面構成とキー操作を再現した、テロップ制作向けのノンリニア編集ソフトです（Premiere Pro 風の配列にも切替可）。
DavinTelop（テロップ編集ソフト）と同じリポジトリ・同じ配布フォルダにあり、`core/`（テロップ描画・タイムコード・SRT/CSV 入出力）を共有しています。
2 つのソフトはそれぞれ単体でも動き、両方起動するとテロップと再生位置が連動します（下の「DavinTelop との連携」）。

## 起動

```
pip install PyQt6 av numpy Pillow
python telocut.py              # 起動（python -m editor でも可）
python telocut.py project.tcut # プロジェクトを開く
python telocut.py a.mp4 b.wav  # 素材を読み込んで起動
python telocut.py --telop      # DavinTelop（テロップ編集）を起動
python telocut.py --mcp        # Claude Code 用の MCP サーバー（標準入出力）
python telocut.py --asset-server --root D:\素材 --port 8770        # アセットサーバー
python telocut.py --render-node --server http://192.168.0.10:8770  # レンダーノード
```

EXE 版では `--mcp` / `--asset-server` / `--render-node` はコンソール版の `TeloCutCLI.exe` で実行します。

外部の ffmpeg は不要です（読み込み・音声解析・プロキシ・書き出しは PyAV 同梱の FFmpeg ライブラリで行います）。
NVENC での書き出しだけは、ffmpeg.exe が PATH 上か TeloCut.exe と同じフォルダにあるときに選べます。

## EXE のビルド

```
build\build_telocut.bat              3 種類すべて
build\build_telocut.bat personal     自分用だけ（free / paid も同様）
```

| 種類 | 中身 | 配る相手 |
|---|---|---|
| `personal`（自分用） | キーなしで Studio（全部の機能）。タイトルに「Studio（自分用）」 | **配らない**（自分と自分のレンダーノードだけ） |
| `free`（無料版） | 無料版に固定。キー入力・お試しはなく「有料版を見る / 購入する」だけ | だれにでも（無料配布） |
| `paid`（有料版） | キーで Pro / Studio。キーが無ければ無料版＋Pro の 14 日間お試し | 購入した人（キーと一緒に） |

- EXE では環境変数 `TELOCUT_EDITION` は効きません（ソースから動かすときだけ）
- 生成物: `dist_telocut\<種類>\TeloCut\`（フォルダ形式。フォルダごと配布）と `dist_telocut\TeloCut_v<バージョン>_<種類>.zip`（バージョンは `editor/version.py` の 1 か所で決まる）
  - `TeloCut.exe`（動画編集）/ `TeloCutAssets.exe`（アセットサーバーの素材だけを扱うアプリ）/ `DavinTelop.exe`（テロップ編集）/ `TeloCutCLI.exe`（コンソール版: MCP・サーバー・レンダーノード）
- バッチは最後に `TeloCut.exe --selftest` で合成・テロップ描画・書き出し・デコードを確認します
- 予期しないエラーは `%USERPROFILE%\.davintelop\telocut_crash.log` に記録されます

## 起動とプロジェクト（Avid と同じ流れ）

起動すると「プロジェクトの選択」が開きます。プライベート（この PC）/ 共有（NAS）/ 外部 のフォルダからプロジェクトを選ぶか、新規作成（名前・ラスター・フレームレート・開始タイムコード）します。
プロジェクトは「プロジェクト名フォルダ / プロジェクト名.tcut」で作られます。ファイル → プロジェクトを閉じる（Ctrl+W）でこの画面に戻ります。

## リアルタイム再生

- 合成は numpy で行い、単純な映像はデコード結果をそのまま表示、テロップは文字の部分だけを重ねる
- 一度表示したフレームは RAM にキャッシュし、2回目以降は即表示
- レンダリング: 重い区間（3 レイヤー以上・色エフェクト・回転・4K 素材など）をバックグラウンドで並列レンダリングし、ローカルディスクにキャッシュ。タイムラインのレンダーバーで状態を表示（赤=要レンダリング、黄=リアルタイム可、緑=済み）。クリップを変更すると、その部分だけが自動で未レンダリングに戻ります
- プロキシ: 4K などの重い素材から全イントラの軽量 H.264 を作り、再生に使う（書き出しは常に元素材）。読み込み時の自動作成も可
- 停止中に自動でバックグラウンドレンダリング（環境設定で有効化）

## プロジェクト保存と NAS ワークフロー

- 保存は一時ファイル経由（NAS 書き込み中に切断されても元ファイルは壊れない）
- 自動保存（既定 5 分）と Attic（ローカルの世代バックアップ、既定 30 世代）。ファイル → Attic から復元
- 共有プロジェクトは `.lock` で同時編集を防止。他の人が開いていると「誰がどの PC で」を表示し、読み取り専用で開ける
- 素材は「絶対パス → プロジェクトからの相対パス → パス置換ルール（例 `\\NAS\video` ↔ `Z:\`）→ 再リンク画面」の順で探す
- キャッシュ・プロキシ・レンダー・Attic は各 PC のローカルに置く（環境設定で変更可）
- メディア管理: NAS 素材をローカルにバックグラウンドコピー（コピー中も編集可）/ 元の場所に戻す / 使用中の素材をフォルダに収集

## マルチディスプレイ（2 画面・3 画面以上）

ディスプレイをつなぐ / 外すと、台数に合わせて自動でレイアウトが切り替わります（1 台に戻すと 1 画面レイアウト）。
画面ごとに次の役割を割り当てます。

| 役割 | 置くもの |
|---|---|
| 編集画面 | コンポーザー（ソース / レコード）を大きく、タイムラインを下に広く、右にエフェクトエディター |
| パネル画面 | 左: プロジェクト / ビン（アセット・AI 画像生成）　中央〜右: テロップ一覧（マーカー・履歴）。仕上げ画面が無いときは右端にプリセット / スコープも |
| 仕上げ画面 | プリセット（SE パッド・AI アシスト）と、大きなビデオスコープ・オーディオミキサー |
| クライアントモニター | レコード（完成映像）を全画面で表示し続ける。テロップの読みやすさを実寸で確認 |
| 使わない | 何も置かない |

推奨の割り当て（メインディスプレイが編集画面。ほかは編集画面に近い順）:

| 台数 | 割り当て |
|---|---|
| 2 台 | 編集 + パネル |
| 3 台 | 編集 + パネル + クライアントモニター |
| 4 台 | 編集 + パネル + 仕上げ + クライアントモニター |
| 5 台以上 | 4 台と同じ（残りは使わない。フルスクリーン再生の出力先になる） |

- ウィンドウ → マルチディスプレイ: レイアウトの切り替え / 推奨の配置に戻す / **画面の割り当て**（画面ごとに役割を選ぶ）/ 編集画面とパネル画面を入れ替える / 自動切り替えの ON・OFF
- 割り当ては画面の組み合わせごとに保存。動かしたパネルの配置も割り当てごとに保存され、次回復元されます（1 画面の配置とは別）
- パネル画面を閉じると 1 画面レイアウトに戻ります。どの画面でもショートカットが効きます
- フルスクリーン再生（Ctrl+Shift+F）は、マルチディスプレイ中はクライアントモニター → 使っていない画面 → 仕上げ画面 の順に出力（ウィンドウ → フルスクリーン出力先 で固定も可）

## 他の編集ソフトとのやり取り

| 形式 | 読み込み | 書き出し | 用途 |
|---|---|---|---|
| AAF | ○ | ○ | Avid Media Composer / Premiere Pro とのシーケンス交換（素材は外部ファイルへのリンク） |
| Premiere Pro プロジェクト（.prproj） | ○（変換） | — | Premiere のプロジェクトからシーケンス・素材の配置を取り出す |
| Final Cut Pro XML（xmeml） | ○ | ○ | Premiere Pro・DaVinci Resolve との交換（マーカー・速度も） |
| EDL（CMX3600） | ○ | ○ | 放送系・オンライン編集との受け渡し |

- ファイル → 他ソフトから読み込み（Ctrl+Alt+I）: 読み込んだシーケンスと素材は新しいビンに入ります。見つからない素材はオフラインとして登録され、再リンクできます
- ファイル → 他の形式で書き出し: AAF / XML / EDL のほか、静止画・音声のみ（WAV）・YouTube チャプター・書き出しキュー
- 対象はカット編集（クリップの位置・使用範囲・トラック・映像と音声のリンク）。エフェクト・トランジション・タイトル・ネストは移りません（読み込み時に注意を表示）
- .prproj はバージョンによって構造が異なるため、うまく読めない場合は Premiere から「Final Cut Pro XML」か AAF で書き出したファイルを読み込んでください

## v0.19.0: モニターで直接動かす・「すぐ使う」をエフェクトに・テレビ / 映画の手法の 50 機能

### レコードモニターで直接動かす（Premiere のダイレクト操作）
- レコードモニターを**ダブルクリック** → そこに映っている一番上のクリップ（映像・画像・テロップ・図形）に青い枠
- 枠の中をドラッグ = **位置**・角の □ = **大きさ**・角の少し外 = **回転**（Shift で 15° ずつ）・Shift + ドラッグ = 縦か横だけ
- 画面の**中心・端・三分割の線にぴったり付く**（ピンクの線。Alt を押している間は付かない）・大きさは 100% に付く
- **矢印キー**で 1px（Shift で 10px）・Esc か何もない所のダブルクリックで終わり・Ctrl+Shift+G（選んだクリップで開始）
- キーフレームのある値は再生ヘッドの位置にキーを打つ・1 回のドラッグが 1 回の「元に戻す」

### 「すぐ使う」をエフェクトとして登録（エフェクトエディターでパラメーターを変えられる・キーフレームも）

モザイク（大きさ・範囲）・揺れ（強さ）・カクカク（何コマごと）・ワイプの枠（角の丸さ・枠の太さ・色・影）・ぼかし背景（ぼかし・暗さ。トラックを増やさない）・
**スポットライト**（周りを暗く）・**虫めがね**（一部を拡大）。すぐ使うのボタン・メニューも、このエフェクトを付けるように変更

3. **実行 → しきい値と見どころの確認**: 音の大きさのグラフに、提案したカット閾値（dB）の線。変えると「無音カット後 約 ○分」がすぐ変わる。
   見どころは 音の大きさ・急な盛り上がり（笑い・驚き）・声のある割合・チャットの量と急増・「草」「すごい」などの反応 から点数を付け、
   点数の高い順に候補を出す（配信マーカーの周りは必ず候補に）。グラフや候補をクリックすると、ソースモニターでその場面を確認できる
4. **OK（作る）**: 選んだ区間ごとにシーケンスを作る — 無音を詰める（つなぎ目に短い音のフェード）→ OP / ED を前後に → 縦なら切り出し位置で
   1080×1920 に → 音声認識で字幕（日本語 / 英語・文節で区切る）
5. **字幕の確認**: 誤字を直す・チェックを外して消す・話者（配信者 / サブ / コメント）を選ぶ（コメントは 💬 付きの吹き出し風の枠）。プレビュー付き → **字幕決定**
6. **書き出し**: 音量をそろえて（−14 LUFS）出力ディレクトリへ（空なら入力動画と同じフォルダ）。形式は DNx / ProRes なども可・ファームにも任せられる。
   他の編集ソフト用に FCPXML と SRT も書ける。作ったシーケンスはビンに残るので、タイムラインで細かく直せる

- 設定（出力先・無音カット / テロップ / 字幕編集の有無・言語・横 / 縦・OP / ED・形式など）は次回も同じ
- 音声認識は faster-whisper（無ければシステムの Python のものを使う）。長い動画ほど時間がかかります

### セキュリティの見直し

| 対象 | 見つかった問題 | 対策 |
|---|---|---|
| アセットサーバー | どの Web サイトからでもサーバーの中身（素材の一覧・パス・コメント）を読めた（CORS が `*`） | `*` をやめた（同じサーバーの画面と TeloCut だけ） |
| アセットサーバー | ほかの Web サイトを開いただけで、ショットの追加・アップロードなどをされ得た（CSRF） | 変更の要求は JSON か `X-TeloCut` ヘッダー付きだけ受け付ける |
| アセットサーバー | アップロード先のフォルダ名に `C:` などを入れると、決まったフォルダの外に書けた（Windows でサーバーを動かす場合） | フォルダ名を 1 つずつ確かめ、アップロード用のフォルダの外には書かない |
| アセットサーバー | 大きなファイルのアップロードをメモリに全部読んでいた（VM のメモリ不足） | 少しずつディスクに書く。JSON は 8 MB まで |
| 連携ブリッジ（127.0.0.1:47310） | ブラウザで開いた Web ページから、TeloCut に命令を送られる余地があった | 起動ごとの合言葉（トークン）が無い要求は断り、HTTP の接続はすぐ切る |
| エクスプレッション | `9**9**9` のような式で固まる | 累乗は上限付きの `pow()` だけ、数字以外の値・長すぎる式は使えない |
| 入れ子シーケンス | プレビューと裏のレンダリングが同時に動くと、合成の状態が混ざる | スレッドごとに持つ |

- アセットサーバーに認証（パスワード）はありません。家の LAN の中だけで使い、ルーターでポート 8770 を外に開けないでください
- エフェクトのプラグイン（plugins フォルダの Python）は、その PC で何でも実行できます。信頼できる物だけを入れてください

### ソースの置き場所（Gitea）と更新の流れ

ソースは自宅の Gitea（`http://192.168.0.37:3000/edit/davintelop`）で管理しています。

1. 編集 PC で変更してコミットし、`git push`
2. サーバー（VM）を最初に入れるとき: 編集 PC で `server\make_vm_command.ps1`（下の表）を実行し、VM に 1 行を貼り付け。
   VM は Gitea から `git clone` して入れる（NAS にファイルを置く以前の方式は `-ViaNas`）
3. 2 回目からの更新は VM で 1 行: `cd ~/telocut-src && git pull && sudo bash server/setup_linux.sh`
   （共有・ポートなどの設定は `/etc/telocut/setup.env` に保存されていて、前回と同じ設定で更新されます）

### 自宅サーバー / レンダーファームの作り方

コピペ 1 行で入るスクリプトを `server/` に用意しています（Windows 用 2 本は配布フォルダにも同梱）。

| やりたいこと | 実行する場所 | コマンド |
|---|---|---|
| Linux VM を Tera Term などで操作して入れる（VM が鍵でしかログインできない場合も可） | 1) 編集 PC で `powershell -ExecutionPolicy Bypass -File server\make_vm_command.ps1 -NasHost 192.168.0.10 -Nfs ES_General,ES_Edit -Smb ES_Render -NasUser edit` 2) VM にログインして、クリップボードの 1 行を貼り付け | （Gitea から取得。NFS / SMB の共有を複数つなぐ） |
| Linux VM（Rocky Linux 推奨・Ubuntu 可）をサーバーにする | 編集 PC（このリポジトリ） | `powershell -ExecutionPolicy Bypass -File server\deploy_to_vm.ps1 -Vm user@192.168.0.20 -Nas //192.168.0.10/video -NasUser nasuser` |
| 同上 + VM をレンダーノードにも | 編集 PC | 上のコマンドの末尾に `-RenderNode` |
| Windows PC をサーバーにする | その PC の TeloCut フォルダ（管理者） | `powershell -ExecutionPolicy Bypass -File install_server_windows.ps1 -Root "\\192.168.0.10\video"` |
| Windows PC をレンダーノードにする | その PC の TeloCut フォルダ | `powershell -ExecutionPolicy Bypass -File install_render_node.ps1 -Server http://192.168.0.20:8770` |
| Docker で動かす | Docker のある VM / NAS | `MEDIA_DIR=/mnt/nas/video docker compose -f server/docker-compose.yml up -d` |

- Linux ではサービス（`telocut-asset` / `telocut-node`）として常時起動。firewalld / SELinux にも対応。ログ: `journalctl -u telocut-asset -f`
- Linux のレンダーノードでは、編集 PC に自分で入れたフォントを `-RenderNode` 指定時に一緒に送ります（Windows 標準フォントはライセンス上送らないので、メイリオ等を使うテロップは Noto Sans CJK で代用されます。見た目を完全にそろえるならレンダーノードは Windows PC に）
- Windows ではログオン時に自動起動（タスク スケジューラ）。削除は同じスクリプトに `-Uninstall`
- 編集 PC: アセットパネルと書き出し（スマート + レンダーファーム）に `http://<サーバー>:8770` を入れる
- 素材のパスが PC と VM で違う場合（`\\NAS\video` と `/mnt/nas`）、編集 PC の環境設定「パス置換ルール」に `/mnt/nas` → `\\NAS\video` を登録すると、サーバーの素材をダウンロードせず直接使います

## DavinTelop との連携（リアルタイム）

両方を起動して DavinTelop の「TeloCut → 🔗 TeloCut とリアルタイム連携」をオンにすると、送る・取り込むの操作なしで常に同じ状態になります。
TeloCut の「AI / 連携 → DavinTelop を開く」や DavinTelop の「TeloCut を起動」で開いた場合は自動でオン。設定は次回も引き継がれます。

| 連携するもの | 内容 |
|---|---|
| テロップ | 追加・削除・本文・開始 / 終了・話者・有効 / 無効・トラック・個別スタイル（どちらで編集しても約 0.3 秒で反映） |
| デザイン | 共通デザイン（フォント・色・縁取り・影・背景・位置）。キャンバスの大きさと fps は TeloCut のシーケンスに合わせる |
| 選択 | どちらかでテロップを選ぶと、もう片方でも選ばれる（DavinTelop で選ぶと TeloCut の再生ヘッドも移動。オフにもできる） |
| 再生位置 | 「TeloCut の再生位置のテロップを自動で選択」をオンにすると、再生に合わせて DavinTelop の行が追従 |
| 取り消し | TeloCut の「元に戻す」も DavinTelop に反映。DavinTelop からの連続した変更は TeloCut で 1 回の取り消しにまとまる |

- 同じテロップは ID（uid）で対応づけるので、TeloCut 側でテロップに付けたエフェクト・アニメーションは消えません
- つないだときに内容が違えば、どちらに合わせるかを聞きます（片方が空なら自動で合わせる）
- TeloCut を閉じても DavinTelop は待ち続け、起動すると自動でつながります（タイトルに状態を表示）
- 手動の「取り込み / 反映」「再生ヘッドを選択テロップへ」なども引き続き使えます
